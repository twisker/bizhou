# 常见问题 FAQ

### 忘了主密码怎么办？
用 `bz recover` + 初始化时生成的**恢复密钥**重设主密码。**两者都丢** = 数据无法解密（端到端加密的必然）。请务必离线保存恢复密钥。

⚠️ 注意：恢复密钥要能用，前提是**保险库文件 `vault.json` 还在**（默认在 `~/.bizhou`）。它是被恢复密钥包裹的那份密文本身，文件丢了，恢复密钥也无从下手。见下一条。

### 换了电脑 / 重装系统，数据还在吗？

⚠️ **在，但你必须把密钥根一起带过去。**

保险库文件 `vault.json`（内含主密码用的盐、以及被主密码和恢复密钥各包裹一份的主密钥）只存在本地密钥根（默认 `~/.bizhou`，可用 `BIZHOU_HOME` 改），**从不上传云端**。没有这个文件，**主密码和恢复密钥都打不开任何东西**——在新机上跑 `bz init` 只会生成一把全新的主密钥，解不开你已有的任何资源。

**现在就该做的事：**

```bash
# 把整个密钥根备份到你信得过的地方（U 盘、离线硬盘、另一台机器）
cp -a ~/.bizhou ~/bizhou-密钥根备份

# 至少也要单独留一份保险库文件
cp ~/.bizhou/vault.json ~/vault-备份.json
```

备份件与**恢复密钥分开存放**：两者放一起，等于把锁和钥匙锁在同一个抽屉里。

**换机步骤：** 把备份的 `~/.bizhou`（至少 `vault.json`）放到新机同一位置 → `bz login` → 输入主密码 → 全部资源可用。

> v1.1.0 计划支持保险库加密上云（云端只存密文，没有主密码/恢复密钥依然解不开），届时换机将只需重输主密码。在那之前，**备份密钥根是唯一的保障**。

### 别人在百度网盘里能看到什么？
一堆随机名的 `.bz` 文件夹（你建的目录结构可见），里面是密文分片。看不到原文件名、内容、大小。见 [安全模型](./security.html)。

### 重复上传同一个文件会怎样？
自动去重跳过——push 前算内容指纹，目标目录已有相同内容就不再传。用 `--force` 可强制。

### 上传/下载传到一半断了？
直接**重跑同一条命令**续传（复用同一密钥与已完成分片）。下载写临时文件、完成才原子落地并做端到端校验，绝不交付半份文件。

### 单文件有大小上限吗？
按 100MB 逻辑分片规避百度单文件上限（`--chunk` 可调）。已实测 >4GB 大文件往返字节一致。

### 一定要装 ffmpeg / pdftoppm 吗？
不。它们只用于**预览生成**且可选——缺失时对应预览优雅跳过，**不影响加密上传/下载**。文本/压缩包列表预览零外部依赖。

### daemon 会占用/删除我的云端文件吗？
**永不删云**。daemon 只增/更新（备份语义）；本地删文件不会镜像删除云端备份。清云端请用 `bz rm` / `bz trash`。

### 支持哪些 shell 补全？
bash / zsh / PowerShell（`bz completion <shell>`）。见 [分享与 shell 补全](./guide-share-completion.html)。云端 bundle id / 路径的动态补全本轮未做。

### 这工具会不会偷偷内嵌百度凭证？
不会。凭证**用户自备**（`.env` 里的 AppKey/SecretKey），代码中无任何硬编码秘密。
