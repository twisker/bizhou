# 验收标准登记表

本文件记载 **敝帚（Bìzhǒu）** 各模块的交付/验收标准：通用交付标准 + 模块专项验收。

---

## 通用交付标准

### 代码质量

| 标准 | 要求 |
|------|------|
| Lint 检查 | 无 error，warning <= 5 |
| 类型检查 | TypeScript strict 模式通过（`tsc --noEmit`） |
| 测试通过 | 所有测试用例 100% 通过（`bun test`），核心库在 Node LTS 下亦通过 |
| 测试覆盖率 | 加密/bundle 核心逻辑 >= 85%，其他核心逻辑 >= 80%，CLI >= 70% |
| 无硬编码秘密 | 代码/仓库中无任何密钥、凭证、token（可审计） |

### 功能完整性

| 标准 | 要求 |
|------|------|
| 需求覆盖 | PRD 中标注的功能均已实现 |
| 边界处理 | 网络中断、断点续传、配额限流、错误主密码、损坏 manifest、忘主密码（恢复密钥）均有合理处理 |
| 错误可读 | 错误按类别给出可读消息 + 规范退出码，绝不静默失败 |

### 安全与正确性（本项目核心）

| 标准 | 要求 |
|------|------|
| 端到端 | 云端只见密文；DEK/KEK/主密码/token 全程客户端，不上传、不托管、不入库、不写明文日志 |
| 往返一致 | 上传→下载→解密→合并后 SHA-256 与原文件一致（字节级） |
| 完整性 | AES-256-GCM tag 校验失败即拒绝解密并报错 |
| 密钥无关机器 | 换机/重装只需重输主密码即可解锁；恢复密钥可在忘主密码时恢复 |
| 分享安全 | 分享码为按需生成、可失效的资源 DEK 导出；7z-AES 导出隐藏文件名且第三方工具可解 |

### 性能

| 标准 | 要求 |
|------|------|
| 大文件不阻塞 | 分片加密走 worker_threads，主线程不卡；内存占用与文件大小解耦（流式） |
| 断点续传 | 上传中断可基于云端 uploadid 续传 |
| 并发/退避 | 依 M0 实测配额设定，避免触发云端限流 |

### 基础设施与发布

| 标准 | 要求 |
|------|------|
| 三平台一致 | Win/macOS/Linux 构建 + 单测通过 |
| CI/CD | push/PR 自动跑 lint+类型+测试+构建（不触真实网盘）；发布人工审批 + 打 tag 触发 |
| 分发 | `@bizhou/core` 发 npm；`bz` 经 Homebrew tap + Scoop bucket，发版自动生成带校验和的 manifest |
| 授权 | 仓库含 Apache-2.0 LICENSE |

## 里程碑验收

### M0 · 技术验证（Sprint 0）

- 一个文件能加密上传 + 下载还原，**字节一致**，且**不被云端限制**。
- OAuth token 获取、precreate/superfile2/create 走通，QPS/配额/限流实测值已记录。

### M1 · 核心库 + CLI（Phase 1）

- >4GB 大文件分片上传 + 还原字节一致；断点续传可用。
- 导出的 7z-AES 包能被第三方 7-Zip / Keka / p7zip + 密码解密。
- `bz` 全部命令可用；CLI 可作为 Skill 被 agent 调用。

## 模块专项验收标准

### crypto

- AES-256-GCM 加解密往返正确；tag 篡改被检出。
- KDF（scrypt/argon2id）参数写入 manifest；同主密码 + 同盐 + 同参数派生 KEK 稳定一致。
- wrappedKey 包裹/解包正确；错误主密码解包失败并报错。
- 恢复密钥可在无主密码时恢复访问。

### bundle

- manifest.json 严格符合 v1 schema；未知/损坏字段被拒绝。
- encMeta 用 DEK 加密，明文中不泄露原文件名。
- `.bz` 文件夹名不透明、不含原文件名。

### chunker

- 默认 100MB 切片、可配置；分片可并行加密且不阻塞。
- 合并还原字节一致。

### baidu

- OAuth（授权码 + device-code）可用、token 可刷新。
- 上传/下载复用云端 4MB 传输分片与 uploadid 断点续传。
- 限流/错误分类正确、退避生效。

### CLI（`bz`）

- 各命令参数、退出码、错误消息符合 PRD §14 规格。
- 口令输入不回显、不入日志。
- 可打包为 agent Skill 调用。
